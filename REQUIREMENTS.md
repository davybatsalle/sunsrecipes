Cette application Android permet de trier et de conserver un ensemble de recettes.

Elle doit permettre les fonctionnalités suivantes:
- scanner à l'aide de l'appareil photo du téléphone des recettes papier. Le scan doit reconnaître à l'aide d'une analyse OCR les ingrédients principaux de la recette. Une feuille papier peut avoir plusieurs recettes d'affichées, le scan doit alors pouvoir séparer les recettes. Le scan doit identifier jusqu'à 2 ingrédients principaux
- enregistrer dans une base de données les recettes scannées, associées à leurs ingrédients principaux, et triées par type d'ingrédient principal (famille), typiquement: viandes, poissons, légumes, desserts, soupes. L'enregistrement doit inclure le scan original, le texte analysé par OCR afin d'avoir un affichage plus lisible, et les ingrédients associés.
- rechercher dans la base de données une recette soit par nom de recette, soit par ingrédient, soit par type d'ingrédient (famille).
- parcourir les recettes par type d'ingrédient (famille), ou par ordre alphabétique. Les recettes doivetn 
- créer un backup de la base de données sur un compte Google Drive.


L'application doit pouvoir tourner sur un téléphone Android. 
La stack choisie n'est pas importante.
